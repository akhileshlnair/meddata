# Vivral Medicine-Adjacent ML Corpus

Working repository for collecting, tracking, and summarizing ML research papers and SFT-useful datasets related to medicine and adjacent clinical workflows.

## Working files

- `notes/papers_log.md`: running reading notes for papers and references
- `notes/datasets_inventory.md`: catalog of datasets found, with usefulness notes
- `notes/research_log.md`: dated activity log for collection progress
- `data/`: local downloads, cached artifacts, and extracted text

## Working rules

- Favor primary sources and official dataset pages.
- Record citations and links as we go.
- Keep the notes document growing continuously as the corpus expands.
- Prefer durable, reproducible downloads over ad hoc scraping.
